    A line at a time.

    1. 01
      Record the line.In the Claude desktop app, install this studio as an app (Install as app, top right), then press Record or Space. Or use Voice Memos or any recorder, one file per line. Quiet room, mic 6–8 inches away, same distance throughout. Pause briefly before and after.
    2. 02
      Add it here.Drop the file on the card or press Enter to choose it. Drop several files at once to fill lines in order by file name.
    3. 03
      Listen. Keep or replace.Play with P, keep with Enter, choose a different file with R. Arrow keys move between lines.
    4. 04
      Ready for edit.When every line is kept, tap Ready for edit and tell Claude you’re done. Claude reads the takes straight from this studio, cleans them up and times the video to your read.

    Takes are stored with this artifact exactly as you upload them, so you can continue on any device. WAV, M4A, MP3, FLAC and WebM all work.
