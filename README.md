## Install a skill

1. Download this repo (Code → Download ZIP) or `git clone https://github.com/kjagsadvisors/keeran.ai`.
2. Copy the skill's folder into `~/.claude/skills/` (every project) or `<your project>/.claude/skills/` (one project).
3. Follow that skill's README for its one-time setup, then ask Claude Code for what it makes.

Or skip all that: paste this repo's link into Claude Code or ChatGPT's Codex and say which skill to set up, e.g. "set up the hormozi-lead-magnet skill".

New skills land here as they're made.
